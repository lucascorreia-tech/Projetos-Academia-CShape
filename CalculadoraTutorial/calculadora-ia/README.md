# Desafio Calculadora Inteligente

Criar uma calculadora seguindos o passo a passo da documentação da Microsoft ([link](https://learn.microsoft.com/en-us/visualstudio/get-started/csharp/tutorial-console?view=vs-2022))

## Desafios
- [] Criar uma funcionalidade que conte a quantidade de vees que a calculadora foi usada.
- [] Armazena uma lista os cálculos recentes e dar capacidade para o usuário excluir essa lista.
- [] Permite que usuários utilizem os resultados na lista acima para realizar novos cálculos.
- [] Adicionar cálculos extras: Raiz Quadrada, 10x, Potência e funções trigonom,etricas
